## 落地 Calibrated Instrument（生产代码，未提交）

用户同意把概念稿落到真实首页，并问「图表是不是该换 ECharts」——结论是**不换**：
`recharts ^3.8.1` 服务 8 个组件、5 种标准图表（Line/Area/Bar/Pie/Composed），
没有任何 ECharts 才有的东西（K线/地图/桑基/canvas 十万点/dataZoom）；换成命令式
`setOption` 要重写 8 个文件、重接 `useChartColors`、重踩打印空白，包还更大。
图标是 `lucide-react ^1.8.0`（两件事别混）。触发更换的条件写在文档里。

落地改动（详见 `docs/design/23-tech-surface-research.md` 第 4 节）：
- `globals.css`：10 支深度令牌（浅/深/打印各一份）、`body::before` 32/160px
  校准网格 + 单一暖光源、`--text-display: 2.875rem`、print 全部复位。
- `card.tsx`：类型化 `elevation` prop → `data-elevation`；**默认不带**，只首页用。
- 首页四层：46px 净资产主读数 + 90 日活动热力带 → 待办条 → 三栏（现金流 `well`）。
- 新增 `AttentionBar`（超预算 + 久未记账）、`ActivityCalendar` + `useActivityCalendar`
  （用**非分页** `transaction_list`；分页版 `page_size` 被后端 clamp 到 100，
  一个季度会静默截断）。
- 10 个 i18n 键，zh/en 各一份。

三个坑，都已修：
1. **`cn()` 吃掉自定义 `text-display`**：tailwind-merge 把未知 `text-*` 当颜色类，
   遇到 `text-foreground` 就删掉 → 主读数变回 13px。改模板字符串拼接。
2. **打印三 pane 塞两列会重叠**（实测 270px）：`flex-1` 卡片在 auto 高度 grid 里
   自动放置错位。改单列文档流 + `break-inside: avoid`。
3. 热力带 `1fr` 列 = 40×6px 横条，改固定 14px 列 + `space-between` 才是周列。

故意没做：90 日净值曲线（后端无序列 IPC，不画假数据）、未对账/未分类计数
（无聚合接口）、玻璃浮卡（没有需要弹出的临时界面，`float` 令牌已备好）。

验证：`vitest 107` / `tsc` / `eslint --max-warnings=0` / `prettier` / `vite build` /
`gen_error_messages --check` 全绿；临时探针截 `screenshots/real-v2-{dark,light,print}.png`
（探针已删，服务器已停）。**代码未提交**。
